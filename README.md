# حكايا السِّراج

موقع تعليمي إسلامي تفاعلي للأطفال (5–10 سنوات)، رفيقه «سِراج»: فانوس مضيء بلا وجه بشري.

إعداد: أ. طلال سعود المهلهل

## الفكرة
- **الشاهد يحكي:** كل قصة يرويها شيء شهد الحدث، مثل غار ثور أو جذع النخلة أو الحوت أو بئر زمزم.
- أذكار الصباح والمساء، وحديقة الأيام، وألعاب تعليمية، وبيت سِراج.

## الضوابط
- لا وجوه بشرية ولا تصوير للأنبياء والصحابة.
- لا موسيقى ولا إيقاع، مؤثرات خفيفة فقط.
- القرآن والسنة الصحيحة فقط، مع ذكر المصدر.
- بلا ذكاء اصطناعي ولا إعلانات ولا جمع بيانات.

**طريقة إضافة حكاية (أدوات في `tools/`):**
1. اعرض كلمات الآية مرقّمة: `python3 tools/ayah.py 7:23`
2. اكتب ملف المصدر `tools/src/<id>.json` (انظر `tools/src/adam-alard.json`)، والآيات فيه `{{سورة:آية|من-إلى}}` ولا تُكتب باليد.
3. `python3 tools/add_story.py tools/src/<id>.json` يضيفها إلى stories/scenes/library/games.
4. شغّل الخادم `python3 -m http.server 8765` ثم افحص: `node tools/film_shots.js <id> out.png` (الفيلم كاملًا بمقاس الجوال)، أو `tools/preview.html?story=<id>` للمشاهد الستة جنبًا إلى جنب.
5. ديكور جديد = دالة في `js/film/sets.js` + حالاته في `css/film.css`.
